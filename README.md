# 🧑‍💻 TermiChat - Terminal Based Chat App using Node.js

TermiChat is a real-time chat application that runs in the terminal. Built with Node.js using TCP sockets, it allows multiple users to join, chat, and see user join/leave events—all from their terminal.

---

## 🚀 Features

- Real-time messaging
- Join/leave user notifications
- Displays list of active users to new joiners
- Clean terminal input/output handling
- Multi-user chat with `net` module (no 3rd-party packages)

---

## 📦 Installation

```bash
git clone https://github.com/your-username/terminal-chat.git
cd terminal-chat
npm run start
```
